# Spec

## Objetivo

Construir un sistema reproducible que convierta notas de medios digitales en una base estructurada de eventos.

## Alcance MVP

1. Ingestar noticias desde CSV semilla.
2. Normalizar columnas a un contrato unico.
3. Generar reporte de calidad de ingesta.
4. Preparar el camino para relevancia, clustering, revision humana y serving.

## Fuera de alcance inicial

- Scraping interactivo con captcha.
- Dashboard productivo.
- Modelo ML de relevancia sin etiquetas.
- Base PostgreSQL.
